# CloudLite Monitor

PT-BR: Cloudlite monitos tem como objetivo ser uma API de monitoramento backend focada no gerenciamento de serviços, authenticação e estudos de arquitetura backend.
EN: CloudLite Monitor is a backend monitoring API project focused on service management, authentication and backend architecture studies.

Built with FastAPI, SQLite and SQLAlchemy, the project was created to practice real backend concepts such as CRUD operations, database persistence, authentication, password hashing and API organization.

## Technologies
- FastAPI
- Python
- SQLite
- SQLAlchemy
- Pydantic
- Git & GitHub

## Features
- Service management API
- CRUD operations
- SQLite database persistence
- User registration
- Password hashing
- REST architecture
